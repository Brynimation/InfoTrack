# InfoTrack Take Home Test

## To run the project

### Cloning the Repository
Clone this github repository by opening up your command line tool of choice and running 
`git clone https://github.com/Brynimation/InfoTrack.git`

### Running the Project
Navigate to the root directory and run 
`npm install`
`npm start`

The backend dotnet microservice and frontend angular server are now both running. To view the UI in your browser, navigate to 
` http://localhost:4200`.

### Using the UI
Use the dropdown to select the location from which you wish to gather solicitor information.
Click the `View Results` button to fetch and display the solicitor information.
